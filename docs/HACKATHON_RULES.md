## Event

Research Agents Hack: Build Multi-Agent AI Systems

## Working timeline

- Build begins: August 8, 2026, 6:00 PM

- Judging: August 18–20, 2026
- Results: August 21, 2026

## Team size

Working event copy says teams of 1–4.

## Required project characteristic

At least two agents with distinct responsibilities should collaborate on a real research bottleneck. Strong submissions should show useful state exchange, evidence/tool use, failure handling, and auditable output rather than a sequence of renamed prompts.

## Submission package

1. Public GitHub/GitLab/Bitbucket repository with source code and setup instructions.
2. Three-minute YouTube (Unlisted) or Loom demo showing agents working on a real input.
3. Project summary up to 200 words covering problem, agent architecture, evidence/data sources, and expected impact.
4. Reproducibility section listing models, APIs, datasets, estimated run cost, and known limitations.

## Working judging weights

- Research utility — 30%
- Agent collaboration — 25%
- Working demo — 20%
- Cost efficiency — 15%
- Originality — 10%

## Safety expectations from supplied copy

Do not upload confidential, personal, patient, unpublished, or license-restricted material without authorization. Cite evidence and disclose model limitations.
